How Snapfile works

  1. Upload a file. No account, no email address, nothing to install. Files up to {{ max_file_size }} MB.
  2. Share the link. You get one link to a download page. Send it by chat, email or phone; a password manager like CredShare works well for the sensitive ones.
  3. Downloaded once, then gone. The file is deleted from the server within seconds of being downloaded, or after {{ file_expiry_hours }} hours if nobody fetches it.

Private by design

Snapfile is a free, anonymous file transfer service for sending large files, documents and archives without leaving a copy behind. It is hosted in Norway and shares nothing with third parties. There are no accounts, no tracking and no cookies. Read the privacy policy, or inspect the open-source code and run your own instance.
